# 🎬 Sara Cinema: Misión Im-Paella-ble 🥘💖
*An Interactive Command-Prompt Romantic Comedy Blockbuster for Windows 11*

---

## 🌟 Overview
Built with love, Spanish culinary passion, and modern terminal ANSI TrueColor engineering for Sara.
This standalone experience runs an interactive, hilarious culinary rom-com movie across **Madrid, San Sebastián, Seville, Valencia, and Barcelona**.

---

## 🚀 How to Run Sara Cinema

### Method 1: The One-Click Experience (Windows CMD)
Double-click `start_movie.bat` from Windows Explorer!

### Method 2: From PowerShell or Terminal
```powershell
npm start
# or
node index.js
```

---

## 🛠️ Personalization (`config.js`)
You can easily customize:
- `yourName`: Your name/nickname (e.g. "Kieran")
- `herName`: Subject's name ("Sara")
- `dateProposal`: The flight code, destination, and dinner menu.
- `settings.soundEnabled`: Toggle sound effects and voiceovers.
