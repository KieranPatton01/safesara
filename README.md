## 🚀 How to Deploy on GitHub Pages

### Method 1: Via GitHub Desktop or Web Interface (Easiest)
1. Go to [GitHub.com](https://github.com) and create a **New Repository** named `sarasuprise` (or `sara-f-rodriguez`).
2. Upload all files from this folder (`index.html`, `style.css`, `app.js`, `README.md`, and the `assets/` directory) to the repository.
3. On GitHub, navigate to your repository's **Settings** tab.
4. Scroll down to **Pages** in the left sidebar.
5. Under **Build and deployment** -> **Source**, select `Deploy from a branch`.
6. Select `main` branch and `/ (root)` directory, then click **Save**.
7. In 1-2 minutes, your website will be live at `https://<your-username>.github.io/<repository-name>/`!

### Method 2: Via Git Command Line
```bash
# Initialize git repository
git init
git add .
git commit -m "Initial commit for Sara F. Rodriguez website"

# Link to your GitHub repository
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```
Then enable GitHub Pages under your repository settings as shown above.
